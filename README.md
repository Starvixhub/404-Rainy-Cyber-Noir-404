# 404: Rainy Cyber-Noir 404

A dark cyber-noir 404 error page featuring animated rain, neon signs, a midnight city, mist, reflections, and interactive rain splash effects.

## Features

* Animated rain system with dynamically generated rain drops
* Cyber-noir night city atmosphere
* Neon `404` and `LOST` signs with flicker effects
* Animated mist and street light glow
* Road reflections
* Interactive rain splash effects on click
* Responsive design
* Animated home navigation

## Built With

* HTML5
* CSS3
* JavaScript
